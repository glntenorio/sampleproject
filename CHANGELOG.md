# Changelog

All notable changes to this project are listed here. The version number also appears in the footer of the live site.

## [0.3.0] - 2026-09-25

### Added
- Instructions page at `/instructions`: the full tester walkthrough on the site itself, with a table of contents, undo table and glossary.

### Changed
- Navigation links to Instructions on every page. Playground links to the on-site instructions. Version bumped to 0.3.0.

## [0.2.0] - 2026-09-25

### Added
- Playground page at `/playground` with five guided tasks and a sandbox of components, including a JavaScript counter.
- SETUP.md: a from-scratch environment guide for testers covering Git, VS Code, cloning, Live Server, commit and push, and Vercel.
- Invite script `--write` flag to grant push access.

### Changed
- Navigation links to the playground. Version bumped to 0.2.0.

## [0.1.0] - 2026-09-25

### Added
- Initial sample page: header, hero, three feature cards, front-end only contact form, footer.
- Mobile-first stylesheet with CSS custom properties.
- Progressive enhancements: mobile nav toggle and inline form validation messages.
- Vercel static configuration with clean URLs.
- Tester guide, issue templates and pull request template.
