Playground

Break things here. That is the point.

This page exists for you to experiment on. Change the words, the colours, the layout, anything. Nothing on this page is precious. If you get stuck, the instructions page explains how to get it running on your computer and how to undo mistakes.

Five things to try

Each one touches a different file. Do them in order if you are new to this, or skip around.

1

Change some text

Open playground.html and change the heading at the top of this page. Save, refresh, and see it update.

2

Change a colour

Open assets/css/styles.css. Near the top, change --color-primary to another colour, like #16a34a. Every button and link follows it.

3

Add a card

Copy one of these <article class="card"> blocks and paste it below the last one. Give it your own title and text.

4

Make the counter count

The counter below only works with JavaScript. Open assets/js/main.js, find the Playground section, and change the step from 1 to 10.

5

Ship it

Commit, push, and open your Vercel URL. Then open a pull request so I can see what you did. The version label in the footer tells you which build you are looking at.
